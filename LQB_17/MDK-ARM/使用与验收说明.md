# 第十七届省赛管路监控程序

## 工程与模块

平台：STM32G431RBT6，HAL，HSI 经 PLL 倍频至 80 MHz，Keil ARM Compiler 5.06 update 7。

头文件位于 `../BSP_Drivers/Inc`，源文件位于 `../BSP_Drivers/Src`：

| 模块 | 职责 |
| --- | --- |
| `app` | 主循环调度：5 ms 按键扫描、10 ms 采集与控制、100 ms 积分与显示数据更新 |
| `bsp_board` | ADC2、TIM3 输入捕获、TIM2 PWM、按键 GPIO、LED 锁存 |
| `bsp_keys` | 20 ms 稳态防抖、按下事件、长按松手事件、跨页长按取消 |
| `monitor` | 压力/流量换算、整数升累计、预设提交、手自动控制与报警 |
| `bsp_display` | 三个界面、固定行列、差异字符刷新 |
| `lcd.c/lcd.h/fonts.h` | 从指定 ES 资源包原样复制的官方 HAL 显示驱动与字库 |

`Core/Src/main.c` 只在 USER CODE 区域接入 `App_Init()` 和 `App_Run()`。
`Core/Inc/stm32g4xx_hal_conf.h` 启用 ADC/TIM；工程已添加四个相应 HAL 源文件和六个 BSP 源文件。
外设初始化在 `bsp_board.c` 中手写；`.ioc` 尚未同步这些外设配置。若重新生成 CubeMX 代码，需要保留这些模块，并确认 HAL 的 ADC/TIM 开关没有被覆盖。

## 接线

依据 ES 中的 CT117E-M4 V1.2 原理图：

| 功能 | 接口 | 板上条件 |
| --- | --- | --- |
| R37 压力电压 | PB15 / ADC2_IN15 | V1.2 板 J11 的 1–2 脚连接 AO2 与 PB15，勿切到 Flash 侧 |
| R39 流量脉冲 | PB4 / TIM3_CH1，AF2 | J9 短接；R39 不是 R40，R40 对应 PA15 |
| PWM 输出 | PA1 / TIM2_CH2，AF1 | 接示波器或逻辑分析仪，共地 |
| B1/B2/B3/B4 | PB0/PB1/PB2/PA0 | 低电平按下 |
| LD1–LD8 | PC8–PC15，PD2 锁存 | 与 LCD 共用总线，驱动写完 LED 后恢复总线 |

ADC 以 3.3 V 为满量程，4 次平均。TIM3 以 1 MHz 计数，16 周期平均测频；连续 50 ms 无边沿判为 0 Hz。
TIM2：PSC=0，ARR=7999，PWM1，高电平有效，初始 CCR2=400，因此初始输出 10 kHz、5%。

## 操作和实现约定

- B1：MAIN → OUTP → PARA → MAIN。离开 OUTP 才提交 TarD/TarP，离开 PARA 才提交 FH/FL/PL/DH。
- B2：MAIN 切换 MAN/AUTO；OUTP 在 TarD/TarP 间选择；PARA 在 FH/FL/PL/DH 间选择。进入设置页面默认第一项。
- B3/B4：设置页加/减一次，不自动连发。MAIN 下按住至少 2 秒后松手，分别零点校准、累计清零。
- 按键保持期间离开所在页面，会取消本次松手功能，避免返回 MAIN 后误清零。
- PWM 每 10 ms 改变 0.01 个百分点，等价于每秒 1 个百分点。自动模式压力进入目标 ±0.5 BAR 区间后保持占空比；输出始终限制为 5%～95%。
- LD1 根据原始频率 >8000 Hz 判断，流量显示才限幅到 40 L/min。LD2/LD3 需各自条件连续超过 2000 ms，条件消失立即清除。
- LD4 在当前模式的目标修改并生效或切换工作模式时启动目标跟踪；达到当前模式目标后熄灭。非当前模式的目标不会干扰当前输出；自动模式到占空比限位但压力未达标时，仍保持目标未达状态。
- 零点电压恰为 3.3 V 时无法进行有限斜率映射，保留原零点；其余低于 3.3 V 的电压允许校准。
- 题目未要求掉电保存，数据保存在 RAM，每次上电恢复题目默认值。FH/FL 按各自 4～40 L/min 范围独立限制，未增加题目未规定的大小关系约束。
- 累计升数使用 `uint32_t`，小数余量单独保存，支持超过 9999999 L；达到 `UINT32_MAX` 后饱和，清零时同时清除余量。

## 待上板验收

以下是预期现象，尚未实际烧录或测量：

1. 上电显示 MAIN/MAN、TarD=5%、TarP=5.0 BAR、FH=20.0、FL=10.0、PL=1.0、DH=65、V=0.0、Q=0；PA1 为 10 kHz、5%。P/F 随真实输入更新。
2. 调 R37，0/1.65/3.3 V 对应约 0/5/10 BAR。约 1.0 V 长按 B3 后松手，V 显示 1.0；随后 2.15 V 对应约 5 BAR，低于零点显示 0。
3. 调 R39，并用仪器确认频率。800 Hz 应为 4.0 L/M，4000 Hz 为 20.0 L/M，8000 Hz 为 40.0 L/M；低于 800 Hz 为零，大于 8000 Hz 时 LD1 亮。拔开 J9 后约 50 ms 失效。
4. 输入 8000 Hz，累计每 1.5 秒增加 1 L。长按 B4 满 2 秒后松手归零，按住期间仍应正常采集和刷新。
5. OUTP 将 TarD 从 5% 调到 10%，停留页面时输出仍为 5%；退出后约 5 秒升至 10%，LD4 先亮后灭。测试下调及 5%/95% 限位。
6. AUTO 下将压力置于目标死区两侧，验证增减方向、1 个百分点/秒和死区保持；切到其他界面仍应运行。
7. F<FL 且实际 D>DH 超过 2 秒后 LD2 亮；F>FH 且 P<PL 超过 2 秒后 LD3 亮。故障中断后重新计时，故障恢复后熄灭；LD5–LD8 始终灭。
8. 对所有参数反复加减检查上下限；验证按键响应、LED 响应均不超过 100 ms，LCD 数据每 100 ms 更新且不闪屏；用示波器实测 10 kHz 频率偏差及占空比偏差。

若无法读取压力，先查 J11；若流量一直为零，先查 J9 和 PB4 波形；若 LED 随 LCD 变化，检查 PD2 锁存接线。重新打开工程后再编译，避免旧的 IDE 内存工程覆盖新的源文件列表。
