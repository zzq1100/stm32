## 验证目标的操作与显示

| 操作 | Phase3验证行为 | 与最终竞赛的区别 |
|---|---|---|
| B1按下 | PWM直接增加5个百分点，封顶95% | 不是B1切页，也没有渐变 |
| B2按下 | PWM直接减少5个百分点，最低5% | 不是模式/参数选择 |
| B3按住不足2秒松开 | 只报告事件 | 无校准 |
| B3按住至少2秒再松开 | 重新采样，尝试更新压力零点 | 这里只测试单页面，跨页取消由后续settings实现 |
| B4 | 只报告按下/松开与持续时间 | 还不能清Q，因为累计模块未实现 |
| LD1～LD4 | 对应B1～B4的稳定按下状态 | 不是最终报警指示 |
| LD5～LD8 | 保持灭 | 与最终要求一致 |

第4行V/P：实时电压与压力；第5行f/F：Hz与L/min，!表示原始f>8000；第6行D/C：占空比配置与CCR；第7行B键/DN或UP/持续毫秒，首次事件以前显示KEY=NONE；第8行N/Z：事件数与零点；第9行A/I/E/ZR：采样有效性、启动错误、校准结果；第10行TEST ONLY。

E是组合位：1=ADC内部校准失败、2=捕获启动失败、4=PWM启动失败。A=0可能来自后续转换失败，不一定改变只记录启动结果的E。ZR：0未请求、1成功、2拒绝、3本次ADC读取失败。UI显示0不自动代表真实传感器输入为0，要一起看有效标记。

## 进入下一阶段以前保持的接口约定

- 页面和按键资格由settings处理，不往bsp_keys加入页面状态。
- 使用最新有效电压做校准；最终控制检查valid，不能把采样失败当真实低压。
- 原始频率用于超频判定，限幅流量用于显示/计量，二者不混用。
- control保存细分占空比请求，bsp_pwm负责量化；渐变不是修改PSC/ARR。
- TIM3回调只记录整数，不在中断中画LCD、改LED或等待毫秒延时。
- 当前尚未验证最终的参数提交、模式切换、长按跨页取消、累计和连续报警；需求追踪表仍保留这些待办，不用阶段测试代替整题验收。
