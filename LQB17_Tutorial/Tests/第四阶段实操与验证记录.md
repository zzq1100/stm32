首轮操作只做以下四步：

1. 用可传输数据的 USB 线连接开发板的下载接口，确认供电；打开 `Firmware/MDK-ARM/LQB17_Tutorial.uvprojx`。
2. 在 Keil 目标下拉框选择 `LQB17_Final`。点击 `Flash → Download`，查看输出是否成功；若失败，保留完整错误文字，先解决下载问题。
3. 下载成功后按板上复位键。观察黑底白字、标题 MAIN、模式 MAN、D=5%、V=0.0V。P、F 随旋钮输入变化；Q 在复位时从 0 开始，有有效流量时会逐渐增加，不能要求它一直保持 0。
4. 短按 B1 三次，标题应依次为 OUTP、PARA、MAIN，每次按下只切换一次。首轮不修改参数。进入 OUTP 时应看到 TarD=5%、TarP=5.0BAR；进入 PARA 时应看到 FH=20.0L/M、FL=10.0L/M、PL=1.0BAR、DH=65%。

反馈时提供：下载是否成功、MAIN 页的 M/D/V、三次 B1 切页是否正确。通过后再进行参数退出生效、压力校准、流量累计与报警验收。界面显示 D=5% 只证明软件显示值，尚不能证明 PA1 实际波形精度。
