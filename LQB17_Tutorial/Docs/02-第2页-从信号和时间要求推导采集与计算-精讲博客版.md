## 一、功能概述：先列任务，不急着选择 API



<a id="p02-01"></a>

### P02-01｜3.1（1）压力

**1．题目原句**

> 电位器模拟压力传感器输出，实现压力实时监测功能。

**2．白话含义**：转动旋钮会改变电压，程序把电压解释为压力。

**3．能确定的条件**：需要持续采集模拟电压。

**4．程序需要记住什么**：当前电压、换算后的压力。

**5．还缺什么信息**：电位器与 MCU 的连接。

**6．去哪里查、怎样核对**：继续读3.3得到 R37，再到原理图查 R37→J11→PB15。

**7．落实到实现与验收**：ADC 负责把电压转成数字，measurement 负责转成压力。

**待执行验收**：后续转 R37，观察电压和压力同步变化。

<a id="p02-02"></a>

### P02-02｜3.1（2）流量

**1．题目原句**

> 脉冲信号模拟流量传感器输出，实现流量实时监测功能。

**2．白话含义**：需要知道脉冲来得多快，不是只知道引脚现在高还是低。

**3．能确定的条件**：测量量是频率。

**4．程序需要记住什么**：相邻边沿对应的计数值、计算出的频率。

**5．还缺什么信息**：信号引脚和可用捕获通道。

**6．去哪里查、怎样核对**：原理图查 R39 和 PB4，再查数据手册的 PB4 复用表。

**7．落实到实现与验收**：使用定时器输入捕获记录边沿，换算成流量。

**待执行验收**：后续转 R39，确认频率与流量随之改变。

<a id="p02-03"></a>

### P02-03｜3.1（3）执行机构

**1．题目原句**

> 单路可调节PWM信号输出，模拟执行机构调速场景。

**2．白话含义**：输出反复高低变化的波形，用高电平占每周期的比例表示控制程度。

**3．能确定的条件**：仅一路；频率和占空比的详细约束在第3页。

**4．程序需要记住什么**：当前实际占空比，不能只保存目标值。

**5．还缺什么信息**：输出引脚、频率和允许范围。

**6．去哪里查、怎样核对**：读3.3确认 PA1，读3.6确认10 kHz、5%～95%；数据手册查 PA1 的定时器复用。

**7．落实到实现与验收**：采用硬件定时器 PWM，让波形生成独立于主循环运行速度。

**待执行验收**：后续核对 CCR 与实际目标变化；波形精度需仪器测量。

<a id="p02-04"></a>

### P02-04｜3.1（4）存储与查询

**1．题目原句**

> 数据存储与查询功能。

**2．白话含义**：系统需要记住设置、累计量等数据，并允许从页面查看。

**3．能确定的条件**：本句没有出现“断电保存”或指定 EEPROM。

**4．程序需要记住什么**：参数、累计量、校准零点等运行状态。

**5．还缺什么信息**：存什么、如何查询、是否跨上电保存。

**6．去哪里查、怎样核对**：合读3.7页面、3.8按键和第6页默认值；不要因为资源包有 AT24C02 就擅自增加写入。

**7．落实到实现与验收**：本方案使用 RAM 保存，按键切页面查询，复位恢复默认状态。

**待执行验收**：后续设置后切页查看；复位时检查按规定恢复默认值。

<a id="p02-05"></a>

### P02-05｜3.1（5）人机操作

**1．题目原句**

> 依试题要求，通过按键完成界面切换、参数设置等功能。

**2．白话含义**：用户通过板上按键操作，不靠修改源码改变每次运行的参数。

**3．能确定的条件**：按键作用由3.8逐项规定。

**4．程序需要记住什么**：当前页面、选中参数、未提交的修改。

**5．还缺什么信息**：各键的具体作用。

**6．去哪里查、怎样核对**：把第4～6页按键规则读完，再在原理图核对 B1～B4 的引脚和有效电平。

**7．落实到实现与验收**：底层输出按键事件，功能层根据所在页面决定操作。

**待执行验收**：后续对同一 B2 在不同页面分别测试，不能全局都切模式。

**知识小结**：结论：电压采集、频率测量、PWM 输出和按键操作各有不同职责。 原因：信号形式和所需信息不同。 关键参数：此处先列功能，具体数值继续从后文提取。 常见误区：用轮询高低电平直接代替可靠测频，或看到存储就加入 EEPROM。

## 二、性能要求：决定主循环不能怎样写



<a id="p02-06"></a>

### P02-06｜3.2（1）按键响应

**1．题目原句**

> 按键响应时间：≤0.1秒。

**2．白话含义**：一次有效操作应在100 ms内被处理，不能让用户等待主循环中的长延时。

**3．能确定的条件**：0.1 s=100 ms；长按的两秒是识别条件，不是普通响应允许延迟。

**4．程序需要记住什么**：上次扫描时刻、输入变化时刻和稳定状态。

**5．还缺什么信息**：扫描周期、防抖时间和其它任务的最坏执行时间。

**6．去哪里查、怎样核对**：本地 HAL 的 stm32g4xx_hal.c 搜 HAL_InitTick、HAL_GetTick；中断文件查 HAL_IncTick。默认时基为1 ms。

**7．落实到实现与验收**：选择每5 ms扫描、连续稳定20 ms确认，并限制每轮显示工作量；不采用 HAL_Delay(2000) 等待长按。

**待执行验收**：后续测试按键时采样仍更新；模拟抖动只产生一次事件。严格100 ms响应需计时记录，肉眼不能证明。

<a id="p02-07"></a>

### P02-07｜3.2（2）指示灯响应

**1．题目原句**

> 指示灯动作响应时间：≤0.1秒。

**2．白话含义**：报警条件最终成立或解除后，灯要及时改变。两秒报警资格计时与灯动作延迟是两件事。

**3．能确定的条件**：LD2/LD3需要先满足连续超过两秒，再满足动作响应要求。

**4．程序需要记住什么**：条件开始时刻、计时有效标记和 LED 状态。

**5．还缺什么信息**：是否存在占用主循环过久的处理。

**6．去哪里查、怎样核对**：对照第6页报警规则；查 HAL_GetTick 时基和 LCD 驱动调用耗时来源。

**7．落实到实现与验收**：主循环及时计算报警并更新灯，不能每两秒才统一检查一次。

**待执行验收**：后续检查2000 ms时尚未满足“超过”，条件满足后及时亮，恢复后及时灭。

<a id="p02-08"></a>

### P02-08｜3.2（3）输出频率误差

**1．题目原句**

> 输出信号频率偏差：±2%。

**2．白话含义**：配置值之外，最终引脚波形也有精度要求。

**3．能确定的条件**：与第3页10 kHz合读，允许频率范围为9800～10200 Hz。

**4．程序需要记住什么**：频率固定，无需不停修改目标频率变量。

**5．还缺什么信息**：定时器真实时钟、分频及周期计数。

**6．去哪里查、怎样核对**：参考手册 TIM 部分查 time-base unit；CubeMX 时钟树查 APB1 timer clock；原理图查主控晶振。

**7．落实到实现与验收**：采用80 MHz定时器时钟、PSC=0、ARR=7999，理论频率=80 MHz÷1÷8000=10 kHz。

**待执行验收**：后续检查寄存器；有仪器时测 PA1。当前没有仪器，不能把计算结果记成实际频率已合格。

<a id="p02-09"></a>

### P02-09｜3.2（4）占空比误差

**1．题目原句**

> 输出信号占空比偏差：±1%。

**2．白话含义**：波形高电平所占比例应接近要求值。它与“每秒变化1%”不是同一项要求。

**3．能确定的条件**：原文没有进一步说明偏差的相对基准，不把一种解释写成官方定义。

**4．程序需要记住什么**：期望的实际占空比与对应 CCR。

**5．还缺什么信息**：计数分辨率、舍入方式和验收口径。

**6．去哪里查、怎样核对**：参考手册查 PWM mode；计算 ARR+1 个计数中每个计数占多少比例。

**7．落实到实现与验收**：8000计数一周期，每计数对应0.0125个百分点；就近取整最大量化偏差0.00625个百分点，设计上也能满足低至5%时的1%相对量化误差要求。

**待执行验收**：后续用寄存器计算量化误差；仪器测得高电平时间/周期后，再按赛事口径判定实际误差。

<a id="p02-10"></a>

### P02-10｜3.2（5）LCD性能

**1．题目原句**

> LCD显示数据刷新时间0.1秒，显示效果清晰、稳定、无噪点。

**2．白话含义**：显示内容每100 ms更新，同时不能闪烁、残留旧字符或出现总线干扰。

**3．能确定的条件**：数据更新周期100 ms；不是每100 ms清屏一次。

**4．程序需要记住什么**：最近刷新时刻、期望字符和已经显示的字符。

**5．还缺什么信息**：官方驱动速度、字库尺寸及LED共用总线的处理。

**6．去哪里查、怎样核对**：BSP/LCD_Driver/MDK5_LCD_HAL 中查 LCD_DisplayChar；原理图对照 PC0～PC15 和 U1。

**7．落实到实现与验收**：按100 ms组织新内容，分批写变化字符，短字符串补空格；核对更新能在周期内完成。

**待执行验收**：后续观察AUTO变MAN、40.0变4.0时无残留；记录更新完成时间，不能只看定时变量。

**知识小结**：结论：性能要求决定任务安排，而不只是最后加几个延时。 原因：阻塞某一功能会延误其它功能。 关键参数：按键/灯≤100 ms，LCD数据100 ms，频率±2%，占空比原文±1%。 常见误区：把防抖、长按计时和报警延时都写成阻塞等待。

## 三、固定硬件来源：从元件追踪到通道



<a id="p02-11"></a>

### P02-11｜3.3（1）R37

**1．题目原句**

> 压力监测功能：调节电位器R37输出模拟测试信号。

**2．白话含义**：测试压力时转的是 R37，不能任选其它电位器。

**3．能确定的条件**：压力输入来源固定为 R37。

**4．程序需要记住什么**：ADC采样结果；R37这个元件名不必成为程序变量。

**5．还缺什么信息**：滑动端连接和 ADC 通道。

**6．去哪里查、怎样核对**：V1.1原理图主控页查 R37→J11→PB15；STM32G431RB数据手册PDF第55页查 PB15，模拟功能为 ADC2_IN15。

**7．落实到实现与验收**：J11短接；CubeMX设置PB15为ADC2通道15，模拟模式、无上下拉；检查J17参考电压连接。

**待执行验收**：后续转R37应改变ADC2读数；不变先查跳线和通道，再查换算。

<a id="p02-12"></a>

### P02-12｜3.3（2）R39

**1．题目原句**

> 流量监测功能：调节电位器R39输出脉冲测试信号。

**2．白话含义**：R39影响板上脉冲电路的频率，送入MCU的是脉冲而非要求采集的电位器电压。

**3．能确定的条件**：测频对象是 R39 对应的脉冲源。

**4．程序需要记住什么**：捕获时刻、周期、原始频率。

**5．还缺什么信息**：信号经过哪条跳线和复用功能。

**6．去哪里查、怎样核对**：原理图查R39、U7、J9、PB4；数据手册PDF第62页复用表PB4行、AF2列为TIM3_CH1。

**7．落实到实现与验收**：J9短接；选择PB4/AF2/TIM3_CH1上升沿输入捕获，保留SWD下载引脚。

**待执行验收**：后续转R39观察捕获间隔变化；不要误转接PA15的R40。

<a id="p02-13"></a>

### P02-13｜3.3（3）PA1

**1．题目原句**

> 脉冲输出功能：执行机构的PWM控制信号通过PA1引脚输出。

**2．白话含义**：评测读取的是PA1波形，其它引脚输出正确也不能替代。

**3．能确定的条件**：PWM输出引脚固定PA1。

**4．程序需要记住什么**：所用定时器句柄和通道。

**5．还缺什么信息**：PA1支持哪个定时器通道。

**6．去哪里查、怎样核对**：数据手册PDF第61页查PA1/AF1→TIM2_CH2；原理图J3第4脚引出PA1。

**7．落实到实现与验收**：CubeMX选择TIM2通道2 PWM，PA1使用AF1；运行时启动对应通道。

**待执行验收**：后续核对PA1复用和TIM2 CCR2；仪器接PA1并与开发板共地。

**知识小结**：结论：题目固定元件或引脚，资料进一步确认通道。 原因：板上连线与芯片复用能力要同时成立。 关键参数：R37→PB15/ADC2_IN15，R39→PB4/TIM3_CH1，PA1→TIM2_CH2。 常见误区：直接套用其它板卡或STM32F1的引脚配置。

## 四、压力换算：为什么校准后必须重新计算斜率



<a id="p02-14"></a>

### P02-14｜3.4 线性映射

**1．题目原句**

> 采集电位器电压并将其线性转换为0～10.0Bar的压力数据，对应输入电压范围[V_offset，3.3V]。

**2．白话含义**：V_offset对应零压力，3.3V对应10BAR，中间按直线比例换算。

**3．能确定的条件**：两个端点确定直线，不是所有时候都用P=V×10/3.3。

**4．程序需要记住什么**：当前电压V、零点V_offset、压力P。

**5．还缺什么信息**：ADC数值怎样转成电压。

**6．去哪里查、怎样核对**：数据手册/参考手册查ADC分辨率与参考电压；原理图查VREF+和J17。

**7．落实到实现与验收**：选择12位ADC；按0～4095映射到名义0～3.3V，再计算P=10×(V−V_offset)/(3.3−V_offset)。

**待执行验收**：计算测试：零点0V时1.65V应为5BAR；零点0.3V时1.8V应为5BAR。

<a id="p02-15"></a>

### P02-15｜3.4 零点校准

**1．题目原句**

> 支持零点校准功能，V_offset为零点偏置电压，校准后，系统应动态更新映射斜率。

**2．白话含义**：把当前电压认作新零点后，剩余电压区间仍需覆盖0～10BAR，因此比例系数会改变。

**3．能确定的条件**：斜率从10/3.3变为10/(3.3−V_offset)。

**4．程序需要记住什么**：保存校准零点；斜率可随公式计算，不一定另存变量。

**5．还缺什么信息**：何时触发，以及V_offset等于3.3V时怎么办。

**6．去哪里查、怎样核对**：第5页查MAIN长按B3释放；除零边界是公式推导出的未定义情况，不是题目另给的规则。

**7．落实到实现与验收**：有效释放时读取当前有效电压。实现选择：3.3V满量程校准拒绝并保留旧零点，避免分母为0；不虚构界面提示。

**待执行验收**：测试校准后当前压力变0，再提高电压检查新斜率；满量程校准不得产生NaN或无穷值。

<a id="p02-16"></a>

### P02-16｜3.4 下限

**1．题目原句**

> 若当前ADC采集到的实时电压值小于零点偏置电压V_offset，则压力值取0。

**2．白话含义**：低于已经校准的零点时，不能显示负压力。

**3．能确定的条件**：V<V_offset取0；相等时公式也得到0。

**4．程序需要记住什么**：使用同一份当前电压与零点比较。

**5．还缺什么信息**：没有缺失的比较阈值；需选择在何处限幅。

**6．去哪里查、怎样核对**：对照公式分子V−V_offset，确认它可能为负；不要用无符号整数先相减。

**7．落实到实现与验收**：在压力换算处处理下限，再把结果交给显示、控制和报警，保证它们使用同一压力。

**待执行验收**：零点0.3V，输入0.2V、0.3V均应0BAR；0.6V应1BAR。

可把换算看成一把可移动零点的尺子：原先3.3V长度代表10BAR，校准到0.3V后只剩3.0V长度代表10BAR。旧斜率会让3.3V只能得到约9.09BAR，违背上端点要求。

这里的“12位”意味着ADC提供4096种整数码，最大码4095。本工程采用端点比例换算；3.3V也是题目给定的名义上限。实际参考电压偏差与ADC误差需要测量评价，不能因公式写对就宣称实际电压无误差。

**知识小结**：结论：校准改变零点和映射斜率。 原因：上端仍必须映射到10BAR。 关键参数：P=10×(V−V_offset)/(3.3−V_offset)，低于零点取0。 常见误区：只减去零点却继续使用旧比例，或忘记满量程分母为0。

## 五、瞬时流量：先测频，再分段换算



<a id="p02-17"></a>

### P02-17｜3.5（1）公式与单位

**1．题目原句**

> 采集脉冲信号频率，瞬时流量按照以下模式计算：F=f/200。F为瞬时流量，单位为升/分钟，f为频率值，单位为Hz。

**2．白话含义**：先测出每秒有多少个脉冲，再按200这个换算系数得到每分钟流量。

**3．能确定的条件**：f单位Hz，F单位L/min；200是题目系数。

**4．程序需要记住什么**：保留原始频率f以及换算结果F，分别命名和标单位。

**5．还缺什么信息**：定时器如何从边沿得到Hz。

**6．去哪里查、怎样核对**：参考手册TIM的input capture章节；HAL源码查HAL_TIM_IC_Start_IT和HAL_TIM_IC_CaptureCallback。

**7．落实到实现与验收**：输入捕获模块计算f，measurement计算F；不能把定时器计数值直接除200。

**待执行验收**：计算测试：4000Hz→20.0L/min，2000Hz→10.0L/min。

<a id="p02-18"></a>

### P02-18｜3.5（1）有效范围

**1．题目原句**

> 合理有效的频率范围：800—8000Hz。

**2．白话含义**：这一段才按公式直接换算，边界也算有效。

**3．能确定的条件**：800≤f≤8000，正常流量范围4～40L/min。

**4．程序需要记住什么**：原始频率和有效性/失联信息。

**5．还缺什么信息**：阈值之外如何处理。

**6．去哪里查、怎样核对**：继续读紧接的两个条件分支；不要自行丢弃所有异常值。

**7．落实到实现与验收**：分清小于、等于和大于；后续单独测试800与8000。

**待执行验收**：800Hz应4.0L/min；8000Hz应40.0L/min且不触发“超过8000”的报警。

<a id="p02-19"></a>

### P02-19｜3.5（1）低频

**1．题目原句**

> 若频率f<800Hz，瞬时流量计为0。

**2．白话含义**：799Hz即便套公式会得到接近4L/min，也必须按题目记0。

**3．能确定的条件**：严格小于800才清零；本句未要求低频点亮LD1。

**4．程序需要记住什么**：当前原始频率、最后收到脉冲的时间。

**5．还缺什么信息**：无脉冲时如何避免一直沿用旧频率。

**6．去哪里查、怎样核对**：从停止输入后的捕获行为分析：不再有中断，旧值不会自动变化，需使用毫秒时基超时判断。

**7．落实到实现与验收**：实现选择：超过50ms没有边沿则报告无有效信号并令流量0；不能只等下一次脉冲更新。

**待执行验收**：测试799Hz→0，800Hz→4；断开输入后不能永久显示先前流量。

<a id="p02-20"></a>

### P02-20｜3.5（1）高频

**1．题目原句**

> 若f>8000Hz，瞬时流量计为40升/分钟，并触发报警功能。

**2．白话含义**：超出上限时显示和累计都按40处理，但报警要知道原始频率已经超限。

**3．能确定的条件**：严格大于8000触发，不能用F>40判断超频。

**4．程序需要记住什么**：原始频率与限幅后的流量必须分开保存。

**5．还缺什么信息**：哪个灯负责这种报警。

**6．去哪里查、怎样核对**：第6页3.9（1）明确LD1；联合检查8000Hz边界。

**7．落实到实现与验收**：measurement把流量限制为40，alarms仍用原始f比较8000。

**待执行验收**：测试8000Hz：40且LD1灭；8001Hz：40且LD1亮。板上旋钮未必能精确到边界，纯逻辑测试需注入数值。

**知识小结**：结论：测频值与流量值必须分开。 原因：限幅会丢失超频信息，报警仍需要它。 关键参数：F=f/200，低于800取0，高于8000取40并报警。 常见误区：先把f裁成8000再判断报警，导致永远无法识别超频。

## 六、累计流量：为什么要保存还没满一升的部分



<a id="p02-21"></a>

### P02-21｜3.5（2）积分周期

**1．题目原句**

> 系统以100ms为采样周期，对瞬时流量进行累加得到累计流量。

**2．白话含义**：流量表示每分钟多少升，要乘这一小段时间，才能得到这段时间实际累计的升数。

**3．能确定的条件**：100ms=1/600分钟，所以每次增量ΔQ=F/600升。

**4．程序需要记住什么**：累计整升数、小数余量、上次累计时刻。

**5．还缺什么信息**：从分钟换到100ms的单位关系。

**6．去哪里查、怎样核对**：写下1分钟=60秒、100ms=0.1秒，计算0.1/60；用HAL_GetTick调度，避免按主循环次数累计。

**7．落实到实现与验收**：totalizer只在每个100ms采样时刻累计一次，使用已经按规则处理的F。

**待执行验收**：30L/min持续20个采样周期应累计1L；40L/min持续15个周期应1L。

<a id="p02-22"></a>

### P02-22｜3.5（2）整升更新

**1．题目原句**

> 当累计流量增量每满1L时更新当前值，累计流量单位为L。

**2．白话含义**：屏幕显示完整升数，小于一升的部分先留着，下一次接着加。

**3．能确定的条件**：不足1L不进位，不能四舍五入成1L。

**4．程序需要记住什么**：整数累计量与小数余量分开存储，清零时两者都清。

**5．还缺什么信息**：大累计量下怎样避免小增量丢失。

**6．去哪里查、怎样核对**：结合第3页至少9999999L的要求，分析大float累计值的分辨率；查C整数范围。

**7．落实到实现与验收**：用uint32_t保存整升，另存有界余量；规划以1/600L为余量单位累计F，满600进1L。

**待执行验收**：40L/min前14次显示0L，第15次显示1L；从9999999L继续累加仍应正确进位。

**知识小结**：结论：累计量是流量乘时间，整数显示不等于整数计算。 原因：每100ms的增量通常小于1L，直接取整会全部丢掉。 关键参数：ΔQ=F/600L；余量以1/600L为单位时，满600进1L。 常见误区：每次加F，或把每次F/600先转成整数。

## 本页验证与排错

| 现象 | 可能原因 | 确认与处理 |
|---|---|---|
| 电压一直0或满量程 | J11/J17、ADC通道错误 | 先看ADC原始码，再查PB15/ADC2_IN15及参考电压 |
| 超频却不报警 | 原始频率被限幅覆盖 | 同时观察frequency与flow，让报警使用前者 |
| 没输入仍显示旧流量 | 没有失联判断 | 观察最近边沿时刻，加入无信号超时 |
| 累计量不增长 | 每次不足1L被取整丢失 | 观察小数余量，满整升再进位 |
| 按键迟钝或屏幕闪 | 长延时、整屏重绘 | 查主循环每项任务用时并限制单轮显示量 |

## 一页纸总结

- 先沿硬件连接确定采集对象，再确定外设配置。
- 压力公式由两个端点推导；校准必须更新零点后的比例。
- 流量分三段计算；原始频率留给LD1，限幅后的流量用于显示、累计和其它报警。
- 100ms累计一次，每次F/600L；整升与余量分开。
- 5ms扫描、20ms防抖、50ms失联判断是本方案选择，不能说成题目原文。
- 性能验收包含实际运行时间和波形误差；软件配置检查只能覆盖其中一部分。
